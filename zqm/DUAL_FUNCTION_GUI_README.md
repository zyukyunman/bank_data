# 金融数据分析工具 - 双功能版使用说明

## 📊 程序概述

这是一个集成了**银行股票分析**和**基金净申购分析**的双功能金融数据分析工具。两个功能处于同一级别，用户可以根据需要在两种分析模式之间自由切换。

## 🎯 主要功能

### 功能一：🏦 银行股票数据分析

- **完整的银行股票报表生成**
- **MA30 周前复权比值分析**
- **红利指数成分股标识**
- **专业颜色标注系统**
- **Excel 报表导出**

### 功能二：📈 基金净申购分析

- **基金净申购份额统计**
- **可视化走势图表**
- **多重数据源获取**
- **智能模拟算法**
- **Excel 数据导出**

### 操作步骤

#### 1. 选择分析功能

- 点击顶部的功能切换按钮
- **🏦 银行股票数据分析**: 进入银行股票分析模式
- **📈 基金净申购分析**: 进入基金净申购分析模式

#### 2. 银行股票分析模式

```
操作流程：
1. 点击 "🔄 获取银行股票数据" 或 "📂 加载缓存数据"
2. 等待数据获取完成
3. 点击 "📈 生成分析报表"
4. 查看 "📋 原始数据" 和 "📊 分析报表" 标签页
5. 点击 "💾 导出Excel报表" 保存结果
```

#### 3. 基金净申购分析模式

```
操作流程：
1. 输入基金代码（如：512890）
2. 选择分析天数（30-180天）
3. 点击 "📊 开始分析"
4. 查看左侧走势图和右侧数据表格
5. 点击 "💾 导出数据" 保存Excel报表
```

## 🔧 功能特色

### 🏦 银行股票分析特色

- **真实 API 数据**: 使用 Tushare API 获取实时数据
- **智能缓存系统**: 自动保存和加载历史数据
- **专业颜色标注**:
  - 🌸 粉红色：红利指数成分股
  - 🟢 深绿色：农商银行
  - 🟡 黄色：低股息率和非破净股票
- **完整财务指标**: PB、股息率、MA30 前复权比值等

### 📈 基金净申购分析特色

- **多源数据获取**: 支持 fund_nav、fund_daily 等多个 API
- **智能代码识别**: 自动识别基金代码格式
- **可视化图表**: matplotlib 绘制专业走势图
- **双色区域填充**: 红色申购区域、绿色赎回区域
- **统计分析**: 累计净申购、7 日均值、申购赎回天数统计

## 📊 示例使用场景

### 场景 1：银行股票投资分析

```
目标：寻找优质银行股投资机会
步骤：
1. 切换到 "🏦 银行股票数据分析"
2. 获取最新银行股票数据
3. 生成分析报表
4. 重点关注：
   - 粉红色标注的红利指数成分股
   - 低PB值的破净股票
   - 高股息率的价值股
   - MA30前复权比值较低的股票
```

### 场景 2：基金资金流向分析

```
目标：分析基金申购赎回趋势
步骤：
1. 切换到 "📈 基金净申购分析"
2. 输入关注的基金代码（如512890）
3. 选择分析周期（建议90天）
4. 分析结果：
   - 查看净申购走势图
   - 关注申购赎回转换点
   - 分析累计净申购趋势
   - 参考7日均值判断短期趋势
```

### 1. 启动程序

```bash
python stock_report_gui.py
```

### 2. 首次使用建议

- **测试连接**: 等待右上角显示"✅ 连接就绪"
