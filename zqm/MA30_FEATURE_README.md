# MA30 周前复权比值功能实现说明

## 📊 功能概述

在银行股票报表中成功添加了"MA30 周前复权"字段，该字段显示**现价/MA30 周前复权的比值**，用于分析当前价格相对于 30 日前复权移动平均价格的位置。

## 🔧 技术实现

### 1. 技术面因子接口获取

- **技术面因子接口**: 使用 Tushare 技术面因子接口 `stk_factor_pro`
  - 接口字段: `ma_qfq_30` (30 日前复权移动平均)
  - 需要权限: 5000 积分以上
  - 优点: 数据准确，计算标准，更新及时

### 2. 比值计算逻辑

- **计算公式**: 现价 ÷ MA30 周前复权价格
- **结果解读**:
  - 比值 > 1: 当前价格高于 30 日前复权均价
  - 比值 < 1: 当前价格低于 30 日前复权均价
  - 比值 = 1: 当前价格等于 30 日前复权均价
- **精度控制**: 保留 3 位小数
- **异常处理**: 数据异常或权限不足显示相应标识

### 3. 智能权限检测

- 自动检测 API 权限级别
- 权限不足时显示"权限不足"标识
- 数据异常时显示"数据异常"标识

3. 计算比值：收盘价 ÷ MA30 前复权价格
4. 格式化结果（保留 3 位小数）
5. 异常处理确保程序稳定运行
