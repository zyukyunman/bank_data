# 银行股分析报表生成器

基于 Tushare 数据的银行股票分析报表工具，支持 GUI 界面操作和 Excel 报表导出。

## 📊 项目简介

这是一个基于 Python 的银行股票数据分析和报表生成工具，支持从 Tushare API 获取实时股票数据，生成专业的分析报表，并导出为 Excel 格式。

## ✨ 主要功能

### 🎯 核心特性

- 🏦 **银行股数据获取**：自动获取所有银行行业股票的实时数据
- 📊 **智能数据分析**：包含股价、市值、财务指标等关键信息
- 🎨 **颜色标注系统**：
  - 证券名称列：粉红色标注 H30269 中证红利低波动指数成分股
  - 序号列：深绿色标注农商行
  - 股息率列：黄色标注低于 2 倍 10 年国债利率的股票
  - PB 列：黄色标注非破净股票
  - PB 排位列：黄色标注前 10 名
- 📁 **Excel 导出**：支持精确的单元格颜色控制
- 🖥️ **GUI 界面**：友好的图形用户界面操作

## 📈 红利低波指数数据源

**当前使用指数**：H30269.CSI（中证红利低波动指数）

- 指数全称：中证红利低波动指数
- 样本数量：50 只证券
- 编制方法：股息率加权，单个样本权重不超过 15%
- 选股标准：连续分红、红利支付率适中、股息率高且波动率低
- 基日：2005 年 12 月 30 日，基点 1000 点

## 🎯 颜色标注规则

### 证券名称列（粉红色）

- 标注条件：属于 H30269 中证红利低波动指数成分股
- 含义：红利低波指数标的，分红水平高且波动率低

### 序号列（深绿色）

- 标注条件：证券名称包含"农商"
- 含义：农村商业银行

### 股息率列（黄色）

- 标注条件：股息率 < 2 × 10 年期国债利率
- 含义：相对债券收益偏低的股票

### PB 列（黄色）

- 标注条件：PB ≥ 1（非破净）
- 含义：市净率大于等于 1 的股票

### PB 排位列（黄色）

- 标注条件：PB 排名前 10 位
- 含义：市净率最低的前 10 只银行股

### 🔧 技术特点

- ✅ **Excel 导出**：支持单个单元格精确颜色控制
- ⚠️ **界面显示**：受 Tkinter 技术限制，只能整行颜色标注
- 💡 **最优方案**：在技术约束下提供最佳用户体验

## 🚀 快速开始

### 环境要求

- Python 3.7+
- Windows 系统
- 有效的 Tushare API Token

### 安装依赖

```bash
pip install -r requirements.txt
```

### 配置 API

在 `config.py` 中配置您的 Tushare API Token：

```python
TUSHARE_TOKEN = "your_token_here"
```

### 运行程序

```bash
# 方法1：直接运行主程序
python stock_report_gui.py

# 方法2：使用启动脚本
python run_gui.py
```

## 📋 使用流程

1. **启动程序**：运行 GUI 应用程序
2. **获取数据**：点击"获取银行股票数据"按钮
3. **生成报表**：点击"生成分析报表"按钮
4. **查看结果**：在"分析报表"标签页查看数据
5. **导出 Excel**：点击"导出 Excel 报表"按钮
