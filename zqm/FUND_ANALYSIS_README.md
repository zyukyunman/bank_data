# 基金净申购份额分析功能说明

## 📈 功能概述

在银行股票报表生成器中新增了第二个核心功能：**基金净申购份额分析**。该功能可以获取指定基金的净申购数据，统计每天的净申购额，并绘制净申购额的走势曲线。

## 🎯 主要特性

### 1. 数据获取能力

- **多源数据获取**: 支持从多个 Tushare API 接口获取基金数据
- **智能代码识别**: 自动识别基金代码格式（支持 6 位数字自动添加交易所后缀）
- **多重备用方案**:
  - 方法 1: 基金净值数据 (`fund_nav`)
  - 方法 2: 基金日线数据 (`fund_daily`)
  - 方法 3: 模拟数据生成（当 API 获取失败时）

### 2. 数据分析功能

- **净申购计算**: 基于成交量和价格变化模拟净申购份额
- **趋势分析**: 计算累计净申购和 7 日均值
- **统计信息**: 总净申购、平均日净申购、净申购/赎回天数统计

### 3. 可视化展示

- **走势图表**: 使用 matplotlib 绘制净申购份额走势图
- **双色填充**: 红色区域表示净申购，绿色区域表示净赎回
- **零轴线**: 清晰显示申购/赎回分界线
- **数据表格**: 实时显示详细的净申购数据明细

## 🔧 使用方法

### 操作步骤

1. 打开程序，切换到"📈 基金净申购分析"标签页
2. 输入基金代码（例如：512890）
3. 选择分析天数（30/60/90/120/180 天）
4. 点击"📊 开始分析"按钮
5. 查看走势图和数据表格
6. 可选择"💾 导出数据"保存 Excel 报表

### 示例基金代码

- **512890**: 易方达中证红利 ETF（已测试可用）
- **159915**: 创业板 ETF
- **510300**: 沪深 300ETF
- **其他 ETF 代码**: 支持 6 位数字基金代码

## 📊 数据字段说明

### 输出数据列

| 字段名           | 说明                | 单位            |
| ---------------- | ------------------- | --------------- |
| 日期             | 交易日期            | YYYY-MM-DD 格式 |
| 收盘价           | 基金单位净值        | 元              |
| 成交量           | 日成交量            | 手              |
| 净申购份额(万份) | 当日净申购份额      | 万份            |
| 累计净申购       | 期间累计净申购      | 万份            |
| 净申购 7 日均值  | 近 7 日净申购平均值 | 万份            |

### 统计指标

- **总净申购**: 分析期间的总净申购份额
- **平均日净申购**: 每日平均净申购份额
- **净申购天数**: 净申购为正的交易日数量
- **净赎回天数**: 净申购为负的交易日数量

## 🔍 技术实现

### 数据模拟算法

当无法获取真实净申购数据时，系统使用智能算法模拟：

1. **基于净值变化**: 分析净值涨跌趋势
2. **结合成交量**: 考虑成交量变化影响
3. **投资者行为建模**:
   - 趋势跟随者（净值上涨时申购）
   - 逆向投资者（净值下跌时申购）
4. **添加市场噪音**: 模拟真实市场的随机波动

### 多重容错机制

- **API 失败处理**: 多个 API 接口自动切换
- **数据格式容错**: 自动适配不同的数据格式
- **异常恢复**: 单个失败不影响整体功能
- **用户友好**: 详细的错误提示和处理建议
